# 微弱电信号测量装置改造计划

## 一、改造概要

将原"悬丝-单线圈-光杠杆"方案改造为**"接收线圈-悬线-大线圈-光杠杆"分离式方案**，并增加双层电磁屏蔽（整体金属网罩 + 接收线圈独立屏蔽）。需要修改的文件包括：

- `基于Arduino嵌入式开发的微弱电信号测量.docx` — 论文正文全文修改
- `2-2 装置平面示意图工程文件.tex` — TikZ 示意图重新绘制
- `基于Arduino嵌入式开发的微弱电信号测量.pdf` — 重新导出

---

## 二、核心原则

> **电路部分（AD8628 跨阻放大器 + ADS1115 ADC + Arduino UNO + OLED）完全不变。**
> 原方案的 PSD → AD8628 → ADS1115 → UNO → OLED 整条电学链路保持原样。
> 变化**仅发生在物理/机械前端**：原来单个矩形线圈同时承担"接收电磁波"和"产生偏转"两个功能，新方案将这两个功能分离到两个独立的线圈。

## 三、新旧方案核心差异对照

| 维度 | 原方案 | 新方案 |
|---|---|---|
| 信号接收 | 单个矩形线圈既是接收体也是偏转体 | 上方200匝接收线圈独立感应电磁信号 |
| 偏转机构 | 矩形线圈+悬丝+镜子 | 圆形大线圈+镜子，由两根并排细线悬挂 |
| 电流传导 | 在线圈内部直接流通 | 从上方接收线圈经两根并排绝缘细线流入下方大线圈 |
| 框架结构 | 开放式重型支架 | 长方体固定框架，两端分别固定激光笔和PSD |
| 电磁屏蔽 | 三层屏蔽（法拉第笼+铝合金屏蔽盒+BNC） | 在三层屏蔽基础上增加整体金属网罩笼罩整个框架 + 接收线圈独立金属网罩 |
| 悬丝/悬线 | 单根悬丝（既是力学支撑又是电流通路） | 两根并排细线（正负分开、外包绝缘），既是悬挂又是电流通路 |
| 磁铁布置 | 大线圈左右各一对永磁体 | 上方接收线圈左右各有磁铁 + 下方大线圈左右各有磁铁 |
| 电路部分 | PSD → AD8628 → ADS1115 → UNO → OLED | **完全不变** |

### 4.4 第2章 系统总体设计

#### 2.1 系统架构 — 重写

原方案四个模块（数据采集、数据放大、数据处理、显示输出）扩展为五个模块：

1. **信号接收模块**（NEW — 独立为一节）：200匝小型接收线圈，左右各置永磁体。待测交变电磁波穿过接收线圈产生感应电流。接收线圈被独立金属网罩包裹屏蔽。通过接线端子将正负极分别连接到两根悬线。

2. **电流传导与力学偏转模块**（重写 — 替代原"数据采集模块"的开头部分）：接收线圈输出的感应电流通过两根并排、外包绝缘的细悬线向下传导，流入悬挂于长方体框架中央的圆形大线圈。大线圈在永磁体均匀磁场中受安培力偏转，带动反射镜同步转动。两根悬线并排走线，既是电流通路也是扭转回复弹簧。

3. **光杠杆读出与信号探测模块**（保持但改写前半段）：激光笔固定于长方体框架一端，PSD固定于另一端。光路不变。PSD 利用横向光电效应将光斑位置转化为两路光电流，**随后送入 AD8628 跨阻放大器转为电压信号**——此处不变。

4. **信号处理模块**（保持）：ADS1115 + Arduino UNO + OLED 完全不变。

5. **电磁屏蔽模块**（NEW）：在原有三层屏蔽（法拉第笼铜网 + BNC屏蔽线 + 铝合金屏蔽盒）基础上，增加整体金属网罩笼罩长方体框架 + 接收线圈独立金属网罩，形成五层屏蔽体系。

#### 2.2 电路设计 — 保持

**完全不变。** PSD → AD8628 跨阻放大器 → ADS1115 ADC → Arduino UNO → OLED 的整条电学链路、接线图和原理图均不变。唯一注意：原理图中标注"光电检测器 → 跨阻放大器"这段是 PSD 到 AD8628 的路径，保持原样。

### 4.5 第3章 硬件设计与实现

#### 3.1 数据采集模块设计 — 完全重写

这是改动最大的章节。原方案描述"单个矩形线圈+悬丝"共约三页内容，需要全部替换为新的双线圈分离结构。新内容结构：

**a) 长方体固定框架**
- 材质：铝合金型材拼接或亚克力激光切割
- 两端分别固定：一端安装激光笔（光杠杆光源），另一端安装 PSD 传感器（带精密滑轨）
- 顶部横梁用于固定悬线上端

**b) 信号接收子模块（200匝接收线圈）**
- 线径和尺寸建议
- 左右两侧对称放置永磁体（N-S 相对布置，增强线圈区域的磁通密度）
- 线圈输出正负两端通过小型接线端子连接两根悬线
- **独立金属网罩**包裹接收线圈及其磁铁，网罩单点接地

**c) 悬线-大线圈-反射镜子模块**
- 两根直径 0.02~0.05mm 磷青铜丝（或钨丝），并排走线，间距极小
- 线外包绝缘漆层或细塑料管，防止正负线短路
- 上端固定于框架顶部横梁的两个相邻锚点，下端分别焊接于大线圈的正负引线端
- 大线圈为圆形，轻质非磁性骨架（如薄塑料环）绕制
- 骨架中心粘贴微型高反射率平面镜（与前文镜子规格一致）
- 大线圈下方加挂配重块，降低重心、增加稳定性

**d) 磁场系统**
- 上方接收线圈：左右各一对永磁体（与前文规格一致）
- 下方大线圈：左右各一对永磁体（比上方更大，以适应大线圈尺寸），构建均匀恒定磁场区

**e) 光杠杆光路**
- 与前文一致：激光 → 反射镜 → PSD

**f) 整体电磁屏蔽**
- 整体金属网罩笼罩整个长方体框架，网罩框架接地
- 接收线圈独立屏蔽：在整体网罩内部，接收线圈区域额外包裹小型金属网罩
- 定性分析双层屏蔽必要性

#### 3.2 数据放大模块设计 — 保持

**完全不变。** AD8628 跨阻放大器的选型理由、偏置电流、零漂移特性等全部保留。此节内容是 PSD 输出光电流 → 电压转换，与新方案的机械前端改动无关。

#### 3.3 数据处理模块设计 — 保持

**完全不变。** ADS1115 + Arduino UNO 的结构、I2C 通信、归一化算子 P 的公式 `P = (V2-V1)/(V2+V1)`、增益量程选择等全部保留。

#### 3.4 电磁屏蔽设计 — 大幅扩展

原方案已有三层屏蔽（法拉第笼铜网 + BNC屏蔽线 + 铝合金屏蔽盒）。新方案在此基础上扩展为五层：

1. **整体金属网罩**（NEW — 第四层）：笼罩整个长方体框架。材质铜网或不锈钢网。网孔密度选择兼顾屏蔽效能与通风/可视性。网罩与系统地单点接地，隔离空间电磁辐射对悬线和大线圈的直接干扰。

2. **接收线圈独立屏蔽**（NEW — 第五层）：小型金属网罩单独包裹200匝接收线圈及其磁铁，独立接地。信号链路的最前端若有噪声混入，后续各级均无法消除。

3. **屏蔽效能定性分析**：简述金属网罩对电磁波的反射损耗和吸收损耗机理，定性说明双层网罩的级联衰减效果。

4. **原三层屏蔽**（保持）：法拉第笼铜网、BNC屏蔽线缆、铝合金屏蔽盒的描述保留不变。

#### 3.5 电源选择 — 保持

**完全不变。** 9V电池为放大模块供电、UNO 5V为 ADS1115 和 OLED 供电——这些与机械前端改动无关。

### 4.6 第4章 系统标定与量化模型

#### 4.1 悬丝扭转劲度系数 k 的静态标定 — 小幅修改

- 术语："悬丝" → "悬线"
- 补充说明：两根悬线并联，等效扭转劲度系数 k_eq = k₁ + k₂ ≈ 2k（假设两线材质和尺寸相同）
- 标定方法（静态力矩平衡法+砝码）不变

#### 4.2 信号量化模型与反推算法 — 小幅修改

原公式 `I = k·x / (2·D·N·B·S)` 在形式上保持不变（最终反推公式形式相同）。但需要在推导过程中补充说明：
- N 和 S 是大线圈（偏转线圈）的匝数和面积，而非接收线圈的
- 接收线圈的200匝决定了感应电流的大小，但反推公式中直接通过位移 x 反算电流 I，不涉及接收线圈参数
- 因此**最终公式不变**，只需在物理建模描述中将 k 写为 k_eq（双线等效劲度系数）

#### 4.3 机械谐振选频特性分析 — 小幅修改

- k → k_eq（双线等效劲度系数）
- J 为大线圈+反射镜+配重的转动惯量（原方案为矩形线圈+镜子+配重）
- 谐振频率公式 f₀ = (1/2π)·√(k_eq/J) 形式不变
- 新增定性讨论：200匝接收线圈的电感可能与悬线-大线圈回路形成额外的电学谐振，可作为一种补充选频机制

### 4.14 新增：信号发射端改造（Si4713 调频发射模块）

原方案在第7章校准方法中使用**RC 电路**作为标定信号源，产生低频微弱电磁波。新方案替换为 **Arduino + Si4713 调频发射模块**：

**Si4713 简介**：Si4713 是 Silicon Labs 的 FM 调频发射芯片，支持 76–108MHz 频段，通过 I2C 接口由 Arduino 控制频率、发射功率和音频调制。相比 RC 电路的优势：
- **频率精确可控**：可编程设置任意发射频率，精度达 10kHz 步进
- **功率可调**：输出功率 - 可调（最大约 +20dBm，天线匹配后），可控制信号强度用于灵敏度测试
- **带音频调制**：可注入正弦波/方波调制信号，模拟不同类型的电磁波
- **扫频能力**：通过 Arduino 程序可自动扫频，用于测绘系统的频率响应曲线

**在文档中的影响范围**：

**a) 第3章 硬件设计**：新增第 3.6 节"信号发射模块设计"，描述 Arduino（可用独立 UNO 或与主控共用）+ Si4713 + 发射天线的硬件连接。Si4713 通过 I2C 与 Arduino 通信，发射天线可采用小型偶极子天线或 PCB 环形天线。

**b) 第7.1节 校准方法**：将原 RC 电路描述替换为：
- Arduino 控制 Si4713 以已知频率和功率发射标定信号
- 接收线圈感应信号，经悬线→大线圈偏转→PSD 读出
- 改变发射功率或频率，记录对应的位移响应
- 通过多组数据拟合标定系数

**c) 第6章 预算**：新增 Si4713 模块（约￥15–25）和独立 Arduino Nano（约￥20，若不与主控共用）。

**d) 第9.3节**：扫频能力可用于材料光电特性测试中的频率响应分析。

**e) 软件**：新增信号发射控制的 Arduino 代码片段（Si4713 库调用，频率/功率设置）。
