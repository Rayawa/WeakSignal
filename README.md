# 基于 Arduino 嵌入式开发与光杠杆放大的微弱电信号测量

> **Weak Electrical Signal Measurement Based on Arduino Embedded Development and Optical Lever Amplification**
>
> 全国大学生物理实验竞赛（创新类）参赛作品 | 量迹无遗小队

---

## 项目概述

本项目设计并实现了一套基于 Arduino 嵌入式系统的微弱电信号测量平台，将传统磁电系检流计原理与现代光电传感技术相结合，实现对 **纳安（nA）级微弱电流** 的精准探测。

通过光杠杆放大 + PSD 位置传感 + 机械谐振选频 + 软硬件协同降噪的技术路线，系统在低成本（约 900 元）下实现了微米级位移检测精度，可替代商用昂贵检流计，广泛应用于光电效应实验、微弱光探测、电磁波探测等场景。

---

## 系统架构

系统由四个核心模块组成：

| 模块 | 名称 | 核心组成 | 功能 |
|------|------|----------|------|
| 模块一 | 微弱电信号发生模块 | Arduino UNO + Si4713 FM 发射芯片 + 天线 | 产生可控频率（76–108 MHz）、功率的标定电磁信号 |
| 模块二 | 信号接收模块 | 200 匝小线圈 + 强磁铁 + 金属网罩屏蔽 | 感应电磁波，产生感应电流 |
| 模块三 | 偏转与光杠杆读出模块 | 大圆形线圈 + 反射镜 + 配重 + 双悬线 + 激光 + PSD 传感器 | 感应电流驱动线圈偏转 → 光杠杆放大 → PSD 读出位移 |
| 模块四 | 数据处理模块 | AD8628 跨阻放大器 + ADS1115 16位 ADC + Arduino UNO + OLED/串口 | 信号调理、采集、归一化算法、显示输出 |

**信号流**：

```
Si4713 发射 → 接收线圈感应 → 感应电流 → 悬线传导
→ 大线圈在磁场中偏转 → 反射镜转动 → 激光偏折
→ PSD 检测 → AD8628 放大 → ADS1115 采集 → Arduino 处理 → 串口/OLED 输出
```

## 关键技术

### 物理原理

- **光杠杆放大**：镜面偏转角 θ → 反射光偏转 2θ → PSD 上光斑位移 $x = 2D\theta$（$D$ 为反射镜到 PSD 距离）
- **安培力偏转**：大线圈通电后在永磁体磁场中受安培力偏转，磁力矩 $M = NIB S$
- **双悬线恢复力矩**：两根并排磷青铜悬线（Φ0.02–0.05 mm）提供扭转恢复力矩
- **机械谐振选频**：通过精确匹配线圈转动惯量和悬线劲度系数，实现物理层面的带通滤波
- **反推公式**：$I = k_{eq} \cdot x / (2 D N B S)$

### 归一化算子

位置解调算法 $P = (V_2 - V_1) / (V_2 + V_1)$，消除激光功率波动的共模噪声，使系统不再依赖恒功率激光源。

### 数字降噪算法

- 中值滤波
- 截尾平均（去掉两端极值后取均值）
- 3 倍标准差异常检测与替换
- 滑动平均滤波（窗口 16）

### 五层电磁屏蔽体系

1. 法拉第笼铜网（100 目）
2. BNC 屏蔽线缆
3. 铝合金屏蔽盒（放大/ADC 模块）
4. 整体金属网罩（笼罩长方体框架）
5. 接收线圈独立金属网罩

## 性能特点

- **检测限**：纳安（nA）级微弱电流
- **分辨率**：远超常规数字万用表和 10 位 ADC 模块
- **成本优势**：约 900 元构建微米级精度测量系统，相比商用产品（数千元）降低 80% 以上
- **可复用性**：82% 的支出属于可复用固定资产
- **物理选频**：机械谐振结构实现硬件层面的带通滤波
- **抗干扰**：五层电磁屏蔽 + 归一化算子消除激光功率波动

## 应用场景

1. **光电效应实验** — 替代传统灵敏检流计，测量纳安级光电流
2. **微弱光探测** — 夜光材料、生物微光、弱激光散射检测
3. **空间电磁波探测** — 50 Hz 工频辐射、无线通信弱场分量
4. **大气静电/空间电磁扰动** — 野外环境自然微弱电信号监测
5. **材料光电特性测试** — 定量表征不同光电材料的灵敏度、线性度、稳定性
