# Arduino 固件说明

两份固件均为独立可编译的 Arduino Sketch（Arduino IDE 直接打开 `.ino` 编译烧录），
已通过静态语法检查。默认参数与《02_理论模型修正与量化设计》一致。

---

## 1. `data_acquisition/` —— 数据采集与处理（主程序）

### 接线（Arduino UNO）

| 器件 | 引脚 | 说明 |
|---|---|---|
| ADS1115 | SDA→A4, SCL→A5, ADDR→GND(0x48) | 16-bit ADC |
| ADS1115 AIN0 | PSD 通道1 跨阻输出 V1 | 单端 |
| ADS1115 AIN1 | PSD 通道2 跨阻输出 V2 | 单端 |
| ADS1115 AIN2/AIN3 | 标定采样电阻 Rs 两端 | 差分（PGA ±0.256V） |
| MCP4725 | SDA→A4, SCL→A5, 0x60 | 标定电流驱动 |
| 串口 | USB | 115200 baud |

### 标定电流回路（重要）

```
MCP4725(Vdac) ── R_drive=100kΩ(0.1%) ── 偏转线圈(R_loop≈100Ω) ── Rs=1kΩ(0.1%) ── Vmid(1.65V 缓冲中点)
```

- DAC 是单极性（0–3.3V），必须用**中点偏置** Vmid=1.65V 实现双向电流：
  `I = (Vdac − Vmid)/(R_drive + R_loop + Rs) ≈ (Vdac − 1.65)/101k`
- ±1 µA 对应 Vdac ≈ 1.549–1.751 V。
- 实际电流用 ADS1115 差分（AIN2−AIN3, ±0.256V 档）测 Rs 压降：±1 mV 满量程。
- Vmid 必须由**运放缓冲的分压器**提供（低阻抗），否则电流不准。

### 串口命令

| 命令 | 功能 |
|---|---|
| `CALSTART` | 扫描 9 级电流并采集 (I, P) 标定点（每级等 5 s 机械稳定） |
| `CALFIT` | 对已采集点最小二乘拟合 I=kP+b，写入 EEPROM |
| `ZERO` | 当前零点清零（b ← −k·P_now） |
| `AVG <n>` | 设置滑动平均窗口（1–64，默认 32） |
| `DAC <0-4095>` | 手动 DAC 输出（调试） |
| `HELP` | 帮助 |

### 默认输出（CSV，10 Hz）

```
t_ms, V1_mV, V2_mV, P, x_mm, I_nA, U_nV, f_Hz
```

- `P = (V2−V1)/(V1+V2)`，归一化位置算子（对光强波动一阶不敏感）
- `x = P·L/2`（mm）
- `I = k·P + b`（nA）
- `U = I·R_loop`（nV，等效感应电动势，仅准静态有效）
- `f`：过零检测频率，**仅 f ≤ 0.10 Hz 有效**（超出显示 0）

### 首次使用流程

1. 上位机（串口助手/ Python）发送 `ZERO` 校准零点；
2. 发 `CALSTART`，等待 ~45 s 扫描完成；
3. 发 `CALFIT`，读取拟合结果；
4. 正常测量，从串口读取 CSV。

## 2. `lowfreq_field_source/` —— 低频磁场信号源

**为什么用它替换 Si4713**：Si4713 是 76–108 MHz FM 发射器，接收线圈直接感应
100 MHz 射频场而非 100 Hz 音频；且悬吊系统机械带宽仅约 0.5 Hz，无法响应
100 Hz 信号（详见《01_技术审查报告》C1）。本固件用 DAC 直接产生**与测量链路
自洽的低频交变磁场**。

### 接线

```
MCP4725(SDA→A4, SCL→A5, 0x60) ── 电流缓冲/小功放 ── 发射线圈（空芯/磁棒，约50匝）
```

### 串口命令

| 命令 | 功能 |
|---|---|
| `SETFREQ <Hz>` | 设置频率（0.005–0.5 Hz，默认 0.10） |
| `SETAMP <%>` | 设置幅度百分比（0–100，默认 50） |
| `ON` / `OFF` | 输出开/停 |
| `HELP` | 帮助 |

### 注意

- 发射线圈需配一个小功放/缓冲级以提供足够电流（Arduino 引脚电流不足）。
- 频率上限建议 ≤ 0.15 Hz（对应机械 f0≈0.5 Hz 的 0.3 倍内），否则测量幅值
  会被机械响应衰减，需用频率响应数据修正。
